# Michael Kariuki — Developer Portfolio

A modern, fast, and responsive personal developer portfolio built with React, Vite, and Tailwind CSS. Showcasing my full-stack development experience, technical skills, and featured projects like the University Exam Portal and Mombasa Sharks Admin Engine.

## Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Forms**: React Hook Form + Zod + Web3Forms
- **Deployment**: GitHub Pages (Automated via GitHub Actions)

## Local Development

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run the Development Server**
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:5173`.

3. **Build for Production**
   ```bash
   npm run build
   ```

## Configuration
All personal data, skills, projects, and social links are managed centrally in `src/data/portfolio.ts` for easy updates.
